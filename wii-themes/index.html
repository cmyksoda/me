Installing

  1. Install Priiloader first. It can save your Wii if a theme goes wrong.
  2. Open Wii Settings and read the version in the top right corner, like Ver. 4.3U.
  3. Download the csm for that region. The csm files are for Wii Menu 4.3 only. The mym is the theme on its own, for building your own csm on any 4.x menu.
  4. Install it with csm-installer or the theme installer of your choice.

Never install these on a Wii U. They're built from the Wii's own menu, and a Wii theme on a Wii U's Wii mode can brick it. Never install a csm for a different region, either.

One bug is known from Piink's thread: on USA consoles, the Start button in the Disc Channel turns blue again once a disc finishes loading.

About Piink

wilsoff released Piink on the WADder forum in May 2011, for USA and European Wiis, and asked anyone who changed it to call small updates v1.1. My v1.1 adds support for Japanese and Korean Wiis, and turns the HOME Menu pink in every language, where the original covered English only. His files are here unchanged.
