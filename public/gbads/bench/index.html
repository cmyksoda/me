GBA DS for the 3DS brings GBA DS to the New 3DS on armGBA’s recompiler, with the second screen on the bottom screen. This page times every scene of a scripted route through each of the 54 games GBA DS supports, 607 scenes in all, on a New 2DS XL, which has the New 3DS XL’s processor. The build timed is version 0.0.6-alpha+speed, commit a253994 on the 3ds branch, timed on November 20 and 21, 2026.

A GBA frame lasts 16.74 ms, so every frame has to be ready within that. We aim for 15 ms, to leave room for heavier moments. All 54 games stay at 15 ms or under in every scene.

    How it’s measured

    Each game starts from power-on with no save and plays a scripted route through its scenes: the boot, menus and cutscenes as they come, then play, battles, races and map screens. On the console, a bench build of each program plays the routes unpaced, with vsync off, and times every 60-frame stretch. A stretch’s time is the average per frame of all the work measured.

    This benchmark’s automation was made with AI assistance. For each game, one AI agent wrote the route from power-on, and a second agent checked it scene by scene and looked for busier play, with both cores reaching the same scene at every step. On the console, each program reads its scripts from the SD card, and this run’s build sends each game’s times to a PC over Wi-Fi as the game ends.
